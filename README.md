# Análisis espacial

Proyecto de análisis espacial y cartografía temática aplicado al estudio territorial, utilizando herramientas de Sistemas de Información Geográfica (SIG) y técnicas de análisis exploratorio espacial.

## Herramientas

* **QGIS** — elaboración y representación cartográfica.
* **GeoDa** — análisis estadístico y exploratorio espacial.
* **Datos censales** — análisis de variables sociodemográficas y territoriales.

## Análisis realizados

El proyecto integra diferentes técnicas de análisis espacial para explorar patrones y relaciones territoriales:

* Análisis de **densidad de población**.
* Cálculo y representación del **Índice de Verde Urbano**.
* Análisis de oportunidades territoriales.
* Cálculo del **Índice de Shannon**.
* Análisis exploratorio de datos censales.
* **Autocorrelación espacial**.
* **Moran's I**.
* Análisis **LISA (Local Indicators of Spatial Association)**.
* Identificación de **clústeres espaciales**.
* Interpretación de patrones territoriales.

## Productos cartográficos

El proyecto incluye mapas temáticos orientados a la representación y análisis de:

* Densidad de población.
* Verde urbano.
* Oportunidades territoriales.
* Índice de Shannon.
* Clústeres espaciales mediante Moran's I y LISA.

## Objetivo

Explorar la distribución espacial de diferentes variables territoriales y sociodemográficas, identificando patrones, concentraciones y asociaciones espaciales que permitan apoyar la interpretación de las dinámicas territoriales.

## Competencias desarrolladas

* Sistemas de Información Geográfica (SIG).
* Cartografía temática.
* Análisis exploratorio espacial.
* Estadística espacial.
* Autocorrelación espacial.
* Análisis de Moran's I y LISA.
* Procesamiento y análisis de datos censales.
* Interpretación territorial.

## Contexto académico

Proyecto desarrollado en el marco de la formación de posgrado en **Ciudades Sostenibles**, con aplicación de herramientas de análisis espacial para el estudio territorial.
